# 项目 Demo 初始化阶段摘要

归档基线：`V1.0.0_20260803`。

## 可追溯的关键步骤

1. 建立单一 Python 包、CLI 与 PyQt6 桌面入口，统一数据加载、标定、检测、2.5D 和拼接模块边界。
2. 采用固定数据集合同读取相机图、平面图、`cali` 与 `scale`，增加异分辨率坐标转换和输入预检。
3. 建立共享鱼眼 K/D、逐机 R/t、拟合初始化、联合 BA 和物理可逆性门禁；不把估计参数表述为测量真值。
4. 接入可选 COLMAP/SfM 特征、匹配、稀疏模型和几何诊断，以逐相机真实三维观测验收注册结果。
5. 将运行链拆分为输入优化中间层、2.5D 输出和拼接输出；每次运行使用唯一 `run_*`，下游只通过 manifest 消费版本化合同。
6. 2.5D 增加基础、SfM 支撑加权和注册相机对照模式，并保留固定高度、来源和可信等级。
7. 参数拼接按候选 K/D/R/t、世界坐标、单位和目标地面执行，输出逐机映射、覆盖、重叠和融合结果。
8. 桌面端支持两个业务页独立选择中间层，后台任务只回填启动时对应的不可变来源。

## 阶段边界

- 2.5D 是平面布局与固定高度表达，不是稠密三维测量。
- SfM 任意尺度坐标不能直接替代业务平面坐标。
- 外部参数只有完成坐标合同验收后才可作为已验证结果；否则必须标记为试算。
- 原始输入、中间层和两个业务输出互不覆盖，已发布运行保持不可变。

逐次尝试、真实数据名称、设备标识、实验数值和无效路线已按正式交付要求清除。
