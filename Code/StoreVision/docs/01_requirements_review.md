# 正式需求

## 功能范围

| 模块 | 要求 | 验收结果 |
| --- | --- | --- |
| 输入 | 读取固定结构的相机图、平面图、`cali` 和 `scale` | 缺失、尺寸冲突或坐标越界时给出明确阻止原因。 |
| 输入优化 | 共享鱼眼 K/D、逐机 R/t、拟合初始化与联合 BA | 输出完整报告、物理门禁和版本化中间层。 |
| SfM | 可选 COLMAP 特征、匹配、稀疏注册与几何诊断 | 只发布具有真实三维观测且通过门禁的候选。 |
| 2.5D | 桌面检测、桌高平面投影、跨相机去重、GeoJSON 和人工复核 | 输出来源、可信等级、候选池和独立复核结果。 |
| 拼接 | 按 K/D/R/t、世界坐标与目标地面完成多相机融合 | 输出逐机映射、覆盖、重叠、透明叠加和融合图。 |
| 桌面端 | 输入优化、2.5D、图像拼接三个一级页面 | 后台运行不阻塞 UI，业务页可独立选择中间层。 |
| 数据治理 | 输入、中间层和业务输出分层且防覆盖 | 同一数据集/输出层交付时只保留当前版本最新口径。 |

## 约束

- 四点平面对应不能单独证明真实内参、畸变或六自由度外参。
- 2.5D 高度来自业务策略，不表述为图像测量值。
- SfM 任意尺度坐标不能直接替代业务平面坐标。
- 未验收的外部坐标合同只能生成 `provisional` / `geometric_trial` 结果。
- 正式仓库不得包含未授权业务数据、真实账户/设备标识或外部项目资料。

## 验收清单

- [ ] 自动化测试全部通过。
- [ ] `store-vision --help` 和桌面冷启动可用。
- [ ] 输入、中间层与两个业务输出合同可独立解析。
- [ ] 输入和已发布中间层不会被覆盖或写回。
- [ ] 仓库通过敏感信息、构建产物和忽略规则检查。
