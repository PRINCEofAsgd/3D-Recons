# 算法设计

## 总体链路

```text
固定结构输入
→ 分辨率适配与输入预检
→ 共享鱼眼 K/D、逐机 R/t 与联合 BA
→ 版本化中间层 manifest
├── 2.5D：检测 → 桌高投影 → 平面锚定 → 去重/复核 → GeoJSON
└── 拼接：去畸变 → 世界地面投影 → 覆盖/重叠 → 羽化融合
```

SfM 是输入侧可选证据：完成特征、匹配和稀疏重建后，以逐相机三维观测和重投影质量验收，发布派生中间层，不直接触发业务输出。

## 数据与坐标

- `cali`：相机像素与平面图百分比的四点关系。
- `scale`：平面百分比与米制世界平面的关系、边界和设备清单。
- 中间层统一记录相机模型、K/D/R/t、外参方向、单位、世界框架、图像到平面图 H 和高度策略。
- 异分辨率输入在统一参考像素系中求解，输出时恢复逐机原生 K；未知裁剪或宽高比冲突直接阻止。

## 输入优化

1. 对逐机四点构建平面 H，并检查面积、条件数和尺寸合同。
2. 在同型号假设下求共享鱼眼 K/D 和逐机 R/t 的有限初始化。
3. 使用鲁棒损失执行联合 BA。
4. 检查焦距、主点、投影单调性、相机高度、朝向与重投影误差。
5. 发布活动候选、诊断报告和中间层 manifest；被拒参数不会伪装为可信真值。

## 2.5D

1. 修复高饱和叠加线并检测白色近矩形桌面候选。
2. 按 K/D/R/t 将轮廓射线与桌高平面求交，再通过 H 锚定到平面图。
3. 结合中心距离、IoU、评分和相机来源跨相机去重。
4. 生成自动对象与弱候选池；人工选择写入独立派生文件。
5. GeoJSON 的 XY 为平面坐标，Z/`height_cm` 为显式业务策略。

## 图像拼接

1. 按 `opencv_fisheye_4` 或 `opencv_pinhole_5` 去畸变。
2. 由 `K·[r1 r2 t]` 推导目标地面单应并映射到米制画布。
3. 过滤相机后方和有效半径外区域。
4. 统计逐像素覆盖与重叠，使用距离权重羽化融合。
5. 对全部输出统一裁剪并记录候选、坐标合同、画布与逐机统计。

## 安全与不可变性

- 原始输入、已有数据库和已发布中间层不写回。
- 每次运行创建唯一目录；显式 `--overwrite` 只用于允许重建的诊断报告。
- 外部命令使用参数数组，不使用 `shell=True`。
- 业务消费者只通过 manifest 解析资源，不扫描任意文件名。
